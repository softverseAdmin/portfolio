# Existing blog with Rabin’s House added

The original header already contains **Portfolio → /portfolio** in its desktop
navigation and mobile menu. The supplied project did not contain that page.

This update adds `src/app/portfolio/page.js`, which opens the game at
`/portfolio-game/index.html`. All of the existing blog’s source, posts, styles,
configuration, dependencies and images are unchanged.

`public/portfolio-game/` contains every unchanged runtime file from Rabin’s House
release 14, commit `bb6f9a2730ca417be848a9a7eb47cc146fc24415`.
The complete original characters, Land Cruiser, house, textures, Mixamo motion
JSONs, Three.js modules and vendored dependencies are hosted alongside your blog.
The game runs as its own full-page document; the blog’s CSS and page layout do
not surround the game or interfere with its camera and controls.

## Local development

Extract the ZIP and open its `portfolio` folder in VS Code. Use the original
project’s Node.js setup, then run:

```sh
npm ci
npm run dev
```

Open http://localhost:3000 and click **Portfolio** in the header or mobile menu.
You can also open http://localhost:3000/portfolio directly.
Edit game code under `public/portfolio-game/`; it is the existing readable source.
No new npm dependency has been added to the blog.

## Vercel

Deploy this combined project as **Next.js**, using the `portfolio` folder as the
project root. Keep your blog’s existing build settings and environment variables.
Use `npm run build` for the build and the normal Next.js output settings.
Do not copy the standalone game’s static `vercel.json` into this blog project:
the game is now served from `public/portfolio-game/` by the existing Next.js app.

The complete game is large. Git deployment is appropriate for this combined
project; an ordinary Vercel Hobby CLI source upload has a documented 100 MB limit.
No Vercel deployment has been performed in this task.

## Preservation and export details

All 138 original application files are retained byte-for-byte. The addition
report records their hashes and the game’s hashes in `portfolio-game-export/`.
The supplied upload’s installed macOS `node_modules`, `.next` build/cache files,
`.git` database and macOS archive metadata are omitted from this portable source
ZIP. The existing `package.json` and `package-lock.json` are unchanged; `npm ci`
installs the correct dependencies for your computer or Vercel.

The original package’s `start` command refers to `server.js`, which was not in
the supplied ZIP. That pre-existing script has been left unchanged. Local
development uses `npm run dev`; a local production run can use
`npm run build` followed by `npx next start`.

The game’s 149 existing automated checks pass, and its complete runtime files
match the saved release. A full Next.js production build and browser/device
playtesting have not been verified here.

The separate **Rabin_House_Interactive_Portfolio_Full_Source_v14.zip** contains
the standalone game source, regression/import scripts, your original host,
visitor and car packages, textures and unmodified source animation inputs.
The reviewed `House_Garden_Model_Package.zip` and `Characters_Model_Package.zip`
Blender authoring packages are supplied as separate unchanged downloads to fit
the per-file transfer limit.
Those large authoring archives are not public downloads in your blog.

The unchanged game stylesheet loads DM Sans and Manrope from Google Fonts and
falls back to system fonts offline. Narration uses the device’s browser voice;
its other sounds are generated by its included Web Audio code. Saved progress
is per browser origin. These are the existing game’s behaviors.
